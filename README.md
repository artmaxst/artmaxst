### Что делаю сейчас

**[PostMeet](https://github.com/artmaxst/postmeet)** — превращает сырой транскрипт встречи в структурированную выжимку для клиента: задачи, решения, открытые риски, готовое письмо-фоллоуап.

**[postmeet-bot](https://github.com/artmaxst/postmeet-bot)** — Telegram-бот, который это автоматизирует. Полностью на Cloudflare Workers: KV + Queues для асинхронной обработки, Claude API через потоковую генерацию (SSE), без своего сервера.
